# Sion Keys changelog

## v0.1.0 — Initial Release

The first Windows x64 version of Sion Keys brings song analysis and practice tools together in one desktop app.

- Analyze a local audio file or a YouTube link to estimate the key and detect chords.
- Follow chord changes on the waveform timeline. Slow down playback or loop a section to practice it.
- View piano, guitar, and bass chord diagrams, transpose the displayed chords, or choose capo shapes.
- Follow the Lyrics Sheet when lyrics are available. Local transcription and verification can use the optional Whisper setup.
- Reopen analyses from History and export chord sheets.

See [installation and update instructions](INSTALLATION.md) and [GitHub Releases](https://github.com/Stefan7kk/sion-keys-releases/releases) for downloads.
