## はじめに

1. [Windows 版 Sion Keys](https://github.com/Stefan7kk/sion-keys-releases/releases/latest) をダウンロードしてインストールします。現在のリリースは [v0.1.0](https://github.com/Stefan7kk/sion-keys-releases/releases/tag/v0.1.0) です。[インストールガイド](../../INSTALLATION.md) に、インストーラーの確認方法があります。
2. 音声ファイルを開くか、対応する YouTube リンクを使います。
3. 曲を分析します。
4. 推定された調と検出されたコードを見ます。
5. 歌詞シートとコード図に沿って進みます。
6. ループ、テンポ、移調、カポで練習します。

インストーラーには分析エンジンが含まれます。手元での歌詞の文字起こしは任意で、インストーラーには入っていません。別のセットアップが Whisper モデルをダウンロードします。曲の分析にそれは不要です。詳細は[インストールガイド](../../INSTALLATION.md)にあります。

## オープンソース

Sion Keys の独自のアプリケーションコードは、公開リポジトリ [Stefan7kk/sion-keys-source](https://github.com/Stefan7kk/sion-keys-source) で [MIT ライセンス](https://github.com/Stefan7kk/sion-keys-source/blob/main/LICENSE) のもと公開されています。

デスクトップアプリは Tauri、React、TypeScript で作られています。音声分析は Python で実装し、メディアの処理には FFmpeg を使います。

実装を読み、問題を報告し、改善を提案できます。同梱された依存関係、画像、モデル、その他の第三者の資源は、それぞれのライセンスのままです。条件は[第三者に関する表記](https://github.com/Stefan7kk/sion-keys-source/blob/main/THIRD_PARTY_LICENSES.md)にあります。

## Sion Keys が生まれた経緯

Sion Keys は、音楽への愛と、信仰の個人的な歩みと、ほかの人が愛する曲を見つけ、理解し、演奏できるよう助けたいという願いから生まれました。

<summary>全文を読む</summary>

私の名前は Stefan Dimov です。2020 年にイエスと個人的に出会ったあと、彼に従い始めました。

音楽はいつも私の心の特別な場所にありました。ピアノと Korg Pa のアレンジャーを弾くのが好きです。しかし音楽がくれるいちばん大きな喜びは、イエスを礼拝し、神に栄光を帰する機会です。

> *「わたしは道であり、真理であり、いのちである。わたしを通してでなければ、だれも父のみもとに来ることはできない。」*
>
> [ヨハネ 14:6, KJV](https://www.bible.com/bible/1/JHN.14.6.KJV)

### なぜ Sion Keys なのか

**Sion Keys** という名は、ヘブル人への手紙 12:22 に出てくるシオンの山に触発されています。そこでは聖書が、生ける神の都と天上のエルサレムについて語っています。

この名を選んだのは、私の信仰と礼拝への愛がこの取り組みの中心にあるからです。私にとって Sion Keys は、音楽アプリ以上のものです。音楽という賜物を通して、役に立つものをほかの人と分かち合う機会です。

[ヘブル人への手紙 12:22, KJV](https://www.bible.com/bible/1/HEB.12.22.KJV)

### Sion Keys はどのように始まったか

私は耳で演奏することを覚えました。美しい曲を聴き、弾きたいのに正しいコードが見つからないもどかしさを知っています。

学んでいるあいだ、コード認識の道具は、自分だけでは聞き取れなかった曲を理解する助けになりました。そこから考えが生まれました。コードを見つけ、調を理解し、愛する曲を覚える、もっと単純で近づきやすい方法があったらどうだろう。

その考えが **Sion Keys** になりました。

目指したのは、曲を探り、練習し、自信を育てるために使える、無料のコードと調の分析ツールです。始めたばかりの人でも、経験のある演奏者でも、ワーシップチームの一員でも使えるように。

### Sion Keys への願い

Sion Keys が、音楽を学ぶことを少し楽に、もう少し喜びに満ちたものにできればと願っています。コードを探す時間を減らし、演奏し、学び、作り、音楽を分かち合う時間を増やしてほしいのです。

このアプリが、たとえ一人でも、愛する曲を覚えること、演奏者として育つこと、礼拝でより大きな喜びを見つけることの助けになるなら、作った意味がありました。

何よりも、ほかの人を励まし、助けるかもしれないものを作る機会を神に感謝しています。
