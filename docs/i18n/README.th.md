## เริ่มอย่างรวดเร็ว

1. ดาวน์โหลด [Sion Keys สำหรับ Windows](https://github.com/Stefan7kk/sion-keys-releases/releases/latest) แล้วติดตั้ง รุ่นปัจจุบันคือ [v0.1.0](https://github.com/Stefan7kk/sion-keys-releases/releases/tag/v0.1.0) [คู่มือติดตั้ง](../../INSTALLATION.md) อธิบายวิธีตรวจไฟล์ติดตั้ง
2. เปิดไฟล์เสียง หรือใช้ลิงก์ YouTube ที่รองรับ
3. วิเคราะห์เพลง
4. ดูกุญแจเสียงที่ประมาณไว้และคอร์ดที่ตรวจพบ
5. ติดตามแผ่นเนื้อร้องและแผนภาพคอร์ด
6. ฝึกด้วยการวน จังหวะ ทรานสโพส และคาโป

ตัวติดตั้งมีเอนจินวิเคราะห์หลัก การถอดเนื้อร้องในเครื่องเป็นทางเลือก และไม่อยู่ในตัวติดตั้ง การตั้งค่าแยกของมันจะดาวน์โหลดโมเดล Whisper การวิเคราะห์เพลงไม่ต้องใช้ส่วนนั้น รายละเอียดอยู่ใน[คู่มือติดตั้ง](../../INSTALLATION.md)

คุณดูการทำให้เป็นจริง รายงานปัญหา และร่วมปรับปรุงได้ ส่วนที่รวมมา ภาพ โมเดล และทรัพยากรบุคคลที่สามอื่นยังใช้สัญญาอนุญาตของตนเอง เงื่อนไขอยู่ใน[ประกาศบุคคลที่สาม](https://github.com/Stefan7kk/sion-keys-source/blob/main/THIRD_PARTY_LICENSES.md)

## เรื่องราวเบื้องหลัง Sion Keys

Sion Keys เติบโตจากความรักในดนตรี จากเส้นทางความเชื่อส่วนตัว และจากความปรารถนาที่จะช่วยผู้อื่นค้นหา เข้าใจ และเล่นเพลงที่พวกเขารัก

<details>
<summary>อ่านเรื่องราวทั้งหมด</summary>

ผมชื่อ Stefan Dimov ผมเริ่มติดตามพระเยซูหลังจากได้พบพระองค์เป็นการส่วนตัวในปี 2020

ดนตรีมีที่พิเศษในใจผมเสมอ ผมชอบเล่นเปียโนและอาร์เรนเจอร์ Korg Pa ของผม แต่ความยินดีที่ยิ่งใหญ่ที่สุดที่ดนตรีให้คือโอกาสนมัสการพระเยซูและถวายเกียรติแด่พระเจ้า

> *“เราเป็นทางนั้น เป็นความจริง และเป็นชีวิต ไม่มีผู้ใดมาถึงพระบิดาได้นอกจากมาทางเรา”*
>
> [ยอห์น 14:6, KJV](https://www.bible.com/bible/1/JHN.14.6.KJV)

### ทำไมจึงเป็น Sion Keys

ชื่อ **Sion Keys** ได้แรงบันดาลใจจากภูเขาศิโยนที่กล่าวในฮีบรู 12:22 ซึ่งพระคัมภีร์พูดถึงเมืองของพระเจ้าผู้ทรงพระชนม์และเยรูซาเล็มบนสวรรค์

ผมเลือกชื่อนี้เพราะความเชื่อและความรักในการนมัสการอยู่ที่ใจของงานนี้ สำหรับผม Sion Keys เป็นมากกว่าแอปดนตรี มันเป็นโอกาสแบ่งปันสิ่งที่เป็นประโยชน์ผ่านของประทานแห่งดนตรี

[ฮีบรู 12:22, KJV](https://www.bible.com/bible/1/HEB.12.22.KJV)

### Sion Keys เริ่มอย่างไร

ผมเรียนเล่นด้วยหู และรู้ว่ามันน่าหงุดหงิดเพียงใดเมื่อได้ยินเพลงงาม อยากเล่น แต่หาคอร์ดที่ถูกไม่เจอ

ระหว่างเรียน เครื่องมือจดจำคอร์ดช่วยให้ผมเข้าใจเพลงที่ฟังเองไม่ออก จากนั้นมีความคิดว่า ถ้ามีวิธีที่เรียบง่ายและเข้าถึงได้มากขึ้นในการค้นคอร์ด เข้าใจกุญแจเสียง และเรียนเพลงที่รัก จะเป็นอย่างไร

ความคิดนั้นกลายเป็น **Sion Keys**

เป้าหมายของผมคือทำเครื่องมือวิเคราะห์คอร์ดและกุญแจเสียงที่ให้ใช้ฟรี เพื่อให้นักดนตรีสำรวจเพลง ฝึก และมั่นใจขึ้น ไม่ว่าจะเพิ่งเริ่ม มีประสบการณ์ หรืออยู่ในทีมนมัสการ

### ความหวังของผมสำหรับ Sion Keys

ผมหวังว่า Sion Keys จะทำให้การเรียนดนตรีง่ายขึ้นเล็กน้อยและมีสุขมากขึ้น ผมอยากให้มันช่วยให้คนใช้เวลาน้อยลงกับการหาคอร์ด และใช้เวลามากขึ้นกับการเล่น เรียน สร้าง และแบ่งปันดนตรี

ถ้าแอปนี้ช่วยแม้เพียงคนเดียวให้เรียนเพลงที่รัก เติบโตในฐานะนักดนตรี หรือพบความยินดีมากขึ้นในการนมัสการ การสร้างมันก็คุ้มแล้ว

เหนือสิ่งอื่นใด ผมขอบพระคุณพระเจ้าสำหรับโอกาสสร้างบางอย่างที่อาจหนุนใจและช่วยผู้อื่น
