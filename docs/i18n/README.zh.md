## 快速开始

1. 下载 [Windows 版 Sion Keys](https://github.com/Stefan7kk/sion-keys-releases/releases/latest) 并安装。当前版本是 [v0.1.1](https://github.com/Stefan7kk/sion-keys-releases/releases/tag/v0.1.1)。[安装指南](../../INSTALLATION.md) 说明如何核对安装程序。
2. 打开音频文件，或使用支持的 YouTube 链接。
3. 分析歌曲。
4. 查看估计的调性和识别出的和弦。
5. 跟随歌词页和和弦图。
6. 用循环、速度、移调和变调夹练习。

安装程序包含核心分析引擎。本地歌词转写是可选的，并不在安装程序里：它的单独安装会下载 Whisper 模型。分析歌曲不需要这一步。详情见[安装指南](../../INSTALLATION.md)。

## 开源

Sion Keys 的原创应用程序代码以 [MIT 许可证](https://github.com/Stefan7kk/sion-keys-source/blob/main/LICENSE) 发布于公开仓库 [Stefan7kk/sion-keys-source](https://github.com/Stefan7kk/sion-keys-source)。

桌面应用使用 Tauri、React 和 TypeScript 构建。音频分析用 Python 实现，媒体处理使用 FFmpeg。

你可以查看实现、报告问题并贡献改进。随附的依赖、图像、模型和其他第三方资源仍使用各自的许可证。条款列在[第三方声明](https://github.com/Stefan7kk/sion-keys-source/blob/main/THIRD_PARTY_LICENSES.md)中。

## Sion Keys 背后的故事

Sion Keys 源于对音乐的爱、一段个人的信心路程，以及帮助别人发现、理解并演奏所爱歌曲的愿望。

我叫 Stefan Dimov。2020 年，我在与耶稣的一次个人相遇之后开始跟随他。

音乐在我心里一直有特别的位置。我喜欢弹钢琴，也喜欢弹我的 Korg Pa 编曲键盘，但音乐带给我最大的喜乐，是敬拜耶稣、将荣耀归给神的机会。

### 为什么叫 Sion Keys？

**Sion Keys** 这个名字受希伯来书 12:22 所提到的锡安山启发。经文在那里说到永生神的城和天上的耶路撒冷。

我选择这个名字，是因为我的信心和对敬拜的爱是这个项目的中心。对我来说，Sion Keys 不只是一个音乐应用。它是借着音乐这份礼物，与别人分享一些有用之物的机会。

[希伯来书 12:22, KJV](https://www.bible.com/bible/1/HEB.12.22.KJV)

### Sion Keys 如何开始

我是靠耳朵学琴的。我知道，听见一首好听的歌、想弹它、却找不到正确和弦，是多么令人着急。

学习的时候，和弦识别工具帮我明白了那些我自己听不出来的歌。由此有了一个想法：如果有一种更简单、更容易使用的方法，让人发现和弦、理解调性、学会自己喜爱的歌，会怎么样？

这个想法后来成了 **Sion Keys**。

我的目标是做一个免费的和弦与调性分析工具，让音乐人用来探索歌曲、练习并建立信心——无论是完全的初学者、有经验的演奏者，还是敬拜团队的成员。

### 我对 Sion Keys 的盼望

我盼望 Sion Keys 让学音乐变得轻松一点、也更有喜乐。我希望它帮助人少花时间找和弦，多花时间演奏、学习、创作并与人分享音乐。

如果这个应用哪怕只帮助一个人学会一首所爱的歌、在音乐上有长进，或在敬拜中找到更大的喜乐，那么做它就是值得的。

最重要的是，我感谢神给我机会做出一件可能鼓励并帮助别人的事。
